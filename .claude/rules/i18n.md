# i18n

_Applies to: `src/components/**/*.tsx`, `src/routes/**/*.tsx`, `src/locales/**/*.ts`_

- Single bundled `i18next` instance (`src/lib/i18n.ts`); resources in `src/locales/{en,es}.ts`. `en` is the source of truth and types every key (`TranslationKey`).
- The app defaults to Spanish; the root route sets `i18n.language` from the `lang` cookie before render to keep SSR/hydration in sync. Tests pin the locale to English (`src/test/setup.ts`).
- Add every user-facing string to **both** `en.ts` and `es.ts`. Never hardcode display text in components.
- Surface errors via `AppError` + `translateError` rather than raw strings.
